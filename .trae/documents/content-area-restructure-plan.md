# 右侧内容区重构计划

## 目标
重构右侧内容区，实现响应式布局、抽屉式任务详情面板、任务项交互优化。

## 当前状态分析
- 内容区域使用两列固定布局（主内容 + 详情面板）
- 详情面板始终显示，不是抽屉模式
- 任务项只有 CheckBox 交互，没有点击和右键菜单
- 添加任务按钮在列表底部，不固定
- 没有右键菜单功能

## 目标结构

```
┌─────────────────────────────────────────────────────┐
│  页面标题                                            │
├─────────────────────────────────────────────────────┤
│  ┌─────────────────────────────────────────────┐    │
│  │  ScrollView (任务列表区域)                    │    │
│  │  ┌─────────────────────────────────────┐    │    │
│  │  │  任务项1  [截止日期]                  │    │    │
│  │  ├─────────────────────────────────────┤    │    │
│  │  │  任务项2  [截止日期]                  │    │    │
│  │  └─────────────────────────────────────┘    │    │
│  └─────────────────────────────────────────────┘    │
├─────────────────────────────────────────────────────┤
│  [添加任务] (固定在底部)                              │
└─────────────────────────────────────────────────────┘

抽屉（默认隐藏，点击任务项时显示）:
┌─────────────────┐
│  任务详情        │
│  ├─ 标题         │
│  ├─ 截止时间     │
│  ├─ 备注         │
│  └─ 子任务       │
└─────────────────┘
```

## 实施步骤

### 1. 重构内容区布局 (MainWindow.xaml)
- 使用 Grid 行布局：标题行 + ScrollView行 + 固定底部行
- ScrollView 包裹任务列表
- 添加任务按钮固定在底部
- 右侧抽屉使用 SplitView 或自定义动画面板

### 2. 实现抽屉组件
- 创建 DetailDrawer 用户控件或直接在 XAML 中实现
- 默认 Width=0 (隐藏)
- 点击任务项时展开/收起
- 使用 VisualStateManager 或 DoubleAnimation 实现动画

### 3. 任务项交互
- 单击任务项：切换抽屉显示/隐藏
- 右键菜单：删除任务
- 截止日期显示在右侧

### 4. 更新 TaskItem 模型
- 添加 Id 属性用于数据库关联
- 添加 Description 属性用于备注
- 添加 SelectedTask 属性用于绑定详情

### 5. 响应式布局
- 使用 VisualStateManager 或 AdaptiveTrigger
- 小屏幕时抽屉覆盖内容，大屏幕时并排显示

3. 点击任务项切换抽屉
4. 右键菜单显示删除选项
5. 添加任务按钮固定在底部
6. ScrollView 正常滚动
