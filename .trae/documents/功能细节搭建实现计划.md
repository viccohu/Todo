# 功能细节搭建实现计划

## 概述
本计划旨在完善任务数据结构和实现功能细节，包括截止时间、提醒时间、重复功能以及修复数据保存问题。

## 一、任务数据结构

每条任务数据应包含以下字段：
1. **任务内容 (Title)** - 任务标题
2. **子任务 (SubTasks)** - 子任务列表
3. **备注 (Description)** - 任务备注
4. **创建时间 (CreatedAt)** - 任务创建时间
5. **截止时间 (DueDate)** - 任务截止日期
6. **提醒时间 (Reminders)** - 提醒设置列表
7. **重复 (Recurrence)** - 重复规则设置

#### 4.4 数据库更新方法
```csharp
public void UpdateTask(TaskItem task)
{
    using var connection = new SqliteConnection($"Data Source={_dbPath}");
    connection.Open();
    var command = connection.CreateCommand();
    command.CommandText = @"UPDATE Tasks 
                           SET Title = $title, 
                               Description = $description,
                               DueDate = $dueDate
                           WHERE Id = $id";
    command.Parameters.AddWithValue("$title", task.Title);
    command.Parameters.AddWithValue("$description", task.Description ?? (object)DBNull.Value);
    command.Parameters.AddWithValue("$dueDate", task.DueDate?.ToString("o") ?? (object)DBNull.Value);
    command.Parameters.AddWithValue("$id", task.Id);
    command.ExecuteNonQuery();
}
```

### 5. WinUI3 系统通知组件（ToastNotification）集成

**重要说明**：
- 提醒设置弹窗：使用普通的 ContentDialog 或 Flyout（UI 对话框）
- 提醒通知：使用 WinUI3 自带的 **ToastNotification** 系统通知组件

#### 5.1 创建提醒服务
- 文件: `Services/ReminderService.cs`
- 依赖：需要添加 NuGet 包 `Microsoft.Toolkit.Uwp.Notifications`

#### 5.2 提醒服务实现
```csharp
using Microsoft.Toolkit.Uwp.Notifications;
using Windows.UI.Notifications;

public class ReminderService
{
    private static ReminderService? _instance;
    public static ReminderService Instance => _instance ??= new ReminderService();
    
    private DispatcherTimer? _checkTimer;
    private DatabaseService _dbService;
    private HashSet<string> _notifiedReminders = new HashSet<string>();
    
    public void Initialize()
    {
        _dbService = new DatabaseService();
        StartReminderCheck();
    }
    
    public void StartReminderCheck()
    {
        _checkTimer = new DispatcherTimer();
        _checkTimer.Interval = TimeSpan.FromMinutes(1);
        _checkTimer.Tick += CheckReminders;
        _checkTimer.Start();
    }
    
    private void CheckReminders(object? sender, object e)
    {
        var now = DateTime.Now;
        var dueReminders = _dbService.GetDueReminders(now);
        
        foreach (var reminder in dueReminders)
        {
            var reminderKey = $"{reminder.TaskId}_{reminder.ReminderDateTime:yyyyMMddHHmm}";
            
            if (!_notifiedReminders.Contains(reminderKey))
            {
                ShowSystemNotification(reminder);
                _notifiedReminders.Add(reminderKey);
            }
        }
    }
    
    private void ShowSystemNotification(Reminder reminder)
    {
        var task = _dbService.GetTaskById(reminder.TaskId);
        if (task == null) return;
        
        new ToastContentBuilder()
            .AddText("📋 任务提醒")
            .AddText(task.Title)
            .AddText($"提醒时间: {reminder.ReminderDateTime:HH:mm}")
            .Show();
    }
}
```

#### 5.3 在 App.xaml.cs 中初始化提醒服务
```csharp

{

    ReminderService.Instance.Initialize();
}
```

## 五、注意事项

1. **性能优化**: 使用 debounce 机制避免频繁数据库操作
2. **数据一致性**: 确保 UI 和数据库状态同步，特别是主界面和抽屉的数据刷新
3. **用户体验**: 
   - 所有弹窗和选择器应有良好的交互反馈
   - 日历选择应有视觉提示
4. **截止日期逻辑**: 截止日到达时自动标记旧任务为过期/完成状态
5. **系统兼容性**: 使用 WinUI3 原生组件确保 Windows 10/11 兼容
6. **ToastNotification 限制**: 确保应用已获得通知权限，在 Windows 设置中启用应用通知
