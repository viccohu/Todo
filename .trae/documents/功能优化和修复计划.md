# 功能优化和修复计划

## 问题概述

1. **任务完成的可点击范围有点大，容易误触**
2. **子任务没保存**
3. **提醒日期中的ToggleSwitch布局调整**

## 详细分析和修复方案

### 1. 任务完成的可点击范围优化

**问题分析**：
- 当前 `CheckBox` 占用了整个宽度区域，点击任何地方都会触发任务完成
- 应该只允许点击复选框本身，而不是整个区域

**修复方案**：
- 修改任务列表的布局结构
- 减小 `CheckBox` 的点击范围，只让复选框本身可点击
- 让任务标题的点击只触发打开抽屉，不触发任务完成

**需要修改的文件**：
- [MainWindow.xaml](file:///d:\Project\Todo\MainWindow.xaml) - 任务项布局
- [MainWindow.xaml.cs](file:///d:\Project\Todo\MainWindow.xaml.cs) - 事件处理

### 2. 子任务保存问题修复

**问题分析**：
- 子任务保存逻辑在创建时有调用，但需要验证
- 可能需要确保子任务状态变更时也立即保存

**修复方案**：
- 验证子任务创建、更新、删除的保存逻辑
- 确保子任务复选框状态变更时立即保存
- 确保子任务加载时从数据库读取完整数据

**需要修改的文件**：
- [Models/SubTask.cs](file:///d:\Project\Todo\Models\SubTask.cs) - 数据模型
- [Services/DatabaseService.cs](file:///d:\Project\Todo\Services\DatabaseService.cs) - 数据库查询
- [MainWindow.xaml.cs](file:///d:\Project\Todo\MainWindow.xaml.cs) - 加载和保存逻辑

### 3. 提醒日期ToggleSwitch布局调整

**当前布局问题**：
- ToggleSwitch 和 TextBlock、ComboBox 的排列不够清晰

**新布局需求**：
```
重复提醒 [ToggleSwitch] | 提醒频率 [下拉选项]
```

**修复方案**：
- 调整 `StackPanel` 内的元素排列
- 添加适当的间距和对齐
- 确保单排显示，保持视觉整洁

**需要修改的文件**：
- [MainWindow.xaml](file:///d:\Project\Todo\MainWindow.xaml) - 提醒设置区域布局

## 实现步骤

### 步骤1：优化任务完成可点击范围
1. 修改任务列表的数据模板
2. 分离复选框和标题的点击事件
3. 确保只有复选框点击触发任务完成

### 步骤2：修复子任务保存问题
1. 更新 `LoadTasks()` 方法，加载子任务
2. 更新 `ShowDrawer()` 方法，从数据库读取子任务
3. 验证子任务复选框变更的保存逻辑

### 步骤3：调整提醒设置布局
1. 修改 ToggleSwitch 布局为"重复提醒 [ToggleSwitch]"
2. 添加"提醒频率"标签
3. 优化元素间距和对齐
