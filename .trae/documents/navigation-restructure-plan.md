# 导航布局重构计划

## 目标
重构 NavigationView 的导航布局，实现正确的层级结构，并支持自定义任务分组功能。

## 当前状态分析
- 当前导航是扁平结构，所有项目都在同一层级
- 没有分组功能，无法管理自定义任务列表
- Footer 只有一个按钮

## 导航目标结构

```
├── 日历视图
├── 重要任务
├── 常驻任务 (可展开/折叠)
│   ├── 日常
│   ├── 周常
│   └── 月常
├── ─────────── (分隔线)
├── [自定义分组区域]
│   ├── 分组1 (可展开/折叠)
│   │   ├── 列表A
│   │   └── 列表B
│   └── 分组2
│       └── 列表C
└── Footer: [新建列表] [新建分组] (横向排列)
```

## 实施步骤

### 1. 数据模型设计
创建以下类：
- `TaskGroup`: 分组模型 (Id, Name, Order, Lists)
- `TaskList`: 列表模型 (Id, Name, GroupId, Order, Tasks)
- 支持拖拽排序的接口

### 2. SQLite 数据库服务
- 创建 `DatabaseService.cs`
- 表结构：Groups, Lists, Tasks
- 支持增删改查和排序更新

### 3. 导航 XAML 重构
修改 `MainWindow.xaml`:
- 固定项：日历视图、重要任务、常驻任务(带子项)
- 分隔线
- 动态加载自定义分组和列表
- Footer 改为 StackPanel 横向排列两个按钮

### 4. 拖拽功能实现
- 使用 `ListView` + `CanDragItems`/`CanDrop`
- 实现拖拽排序和跨分组移动
- 更新数据库排序字段

### 5. 交互功能
- 新建分组/列表：直接添加，支持双击重命名
- 右键菜单：删除、重命名
